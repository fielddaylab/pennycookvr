# Voiceover Line Naming Scheme

First character: Day/Level Number 
Second character: Location  (t = Tent, b = Bluff, r = Rookery)
Third character: Character (s = Sebastian (player), m = Margo, p = Penny/partner)
Fourth & Fifth character: Number in sequence, unique identifier

Example: `Day2/Bluff/2bm04.mp3`
Day 2, Bluff, Margo, 4th line from Margo in that level and location.
